# 03：文件、目录、路径与文本

PowerShell 通过 provider 将文件系统、注册表、证书等暴露成类似驱动器。本文重点讲文件系统。

## 1. 位置命令

```powershell
Get-Location
Set-Location C:\Windows
Push-Location C:\Temp
Pop-Location
```

- `Get-Location`：当前路径，别名 `pwd`。
- `Set-Location`：切换路径，别名 `cd`、`chdir`。
- `Push-Location`：保存当前位置后切换，别名 `pushd`。
- `Pop-Location`：返回保存的位置，别名 `popd`。

查看驱动器：

```powershell
Get-PSDrive
Get-PSDrive -PSProvider FileSystem
```

## 2. 列出目录：`Get-ChildItem`

```powershell
Get-ChildItem
Get-ChildItem C:\Windows
Get-ChildItem -Force
Get-ChildItem -File
Get-ChildItem -Directory
Get-ChildItem -Recurse
```

常用参数：

| 参数 | 作用 |
|---|---|
| `-Path` | 支持 PowerShell 通配符 |
| `-LiteralPath` | 路径完全按字面解释 |
| `-Filter` | provider 侧筛选，通常最快 |
| `-Include` / `-Exclude` | 包含/排除模式 |
| `-File` / `-Directory` | 只要文件/目录 |
| `-Force` | 包含隐藏项 |
| `-Recurse` | 递归 |
| `-Depth` | 限制递归层数，PowerShell 7 更常用 |

示例：

```powershell
Get-ChildItem C:\Windows -Filter '*.dll' -File
Get-ChildItem . -Recurse -File -Include '*.rs','*.toml'
```

## 3. 项目查询：`Get-Item` 与 `Test-Path`

```powershell
Get-Item file.txt
Get-Item Env:Path
Test-Path file.txt
Test-Path file.txt -PathType Leaf
Test-Path output -PathType Container
```

- `Leaf`：文件等叶节点。
- `Container`：目录等容器。

不存在时避免报错：

```powershell
if (Test-Path -LiteralPath $path) {
  Get-Item -LiteralPath $path
}
```

## 4. 创建：`New-Item`

目录：

```powershell
New-Item -ItemType Directory -Path C:\Temp\demo -Force
```

文件：

```powershell
New-Item -ItemType File -Path C:\Temp\demo\empty.txt -Force
```

符号链接（通常需要开发者模式或管理员权限）：

```powershell
New-Item -ItemType SymbolicLink -Path link.txt -Target target.txt
```

## 5. 复制：`Copy-Item`

```powershell
Copy-Item source.txt destination.txt
Copy-Item sourceDir destinationDir -Recurse
Copy-Item '*.txt' backup -Force
```

保留目录内容但不额外套一层目录：

```powershell
Copy-Item 'source\*' destination -Recurse
```

`-Container` 控制复制目录结构；复制前应确认源/目标语义。

## 6. 移动和重命名

```powershell
Move-Item old.txt C:\Archive\old.txt
Rename-Item old.txt new.txt
```

批量添加前缀：

```powershell
Get-ChildItem -File '*.txt' | ForEach-Object {
  Rename-Item $_ -NewName "backup-$($_.Name)"
}
```

先使用 `-WhatIf` 预演：

```powershell
Rename-Item old.txt new.txt -WhatIf
```

## 7. 删除：`Remove-Item`

```powershell
Remove-Item file.txt
Remove-Item directory -Recurse
Remove-Item directory -Recurse -Force
```

高风险命令先预演：

```powershell
Remove-Item C:\Temp\old -Recurse -Force -WhatIf
```

要求确认：

```powershell
Remove-Item file.txt -Confirm
```

PowerShell 删除通常不进入回收站。

## 8. 路径组合和解析

```powershell
Join-Path C:\Temp 'file.txt'
Split-Path C:\Temp\file.txt -Parent
Split-Path C:\Temp\file.txt -Leaf
Resolve-Path .\file.txt
Convert-Path .
```

- `Join-Path`：正确处理分隔符。
- `Split-Path`：取父目录、叶名称、扩展相关部分。
- `Resolve-Path`：解析已存在路径、通配符和相对路径。
- `Convert-Path`：转换为 provider 对应的本机路径。

.NET 路径 API：

```powershell
[IO.Path]::GetFullPath('.\output')
[IO.Path]::GetExtension('file.tar.gz')
[IO.Path]::GetFileNameWithoutExtension('file.txt')
[IO.Path]::GetTempPath()
```

## 9. 读取文本：`Get-Content`

```powershell
Get-Content file.txt
Get-Content file.txt -Raw
Get-Content file.txt -TotalCount 10
Get-Content file.txt -Tail 20
Get-Content app.log -Wait
```

- 默认逐行输出字符串数组。
- `-Raw` 返回一个完整字符串。
- `-Tail` 读取末尾。
- `-Wait` 持续监听追加内容，类似 `tail -f`。

指定编码：

```powershell
Get-Content file.txt -Encoding utf8
```

二进制读取应使用 .NET：

```powershell
$bytes = [IO.File]::ReadAllBytes('file.bin')
```

## 10. 写文本

覆盖：

```powershell
'hello' | Set-Content file.txt -Encoding utf8
```

追加：

```powershell
'next line' | Add-Content file.txt -Encoding utf8
```

`Out-File` 写格式化显示：

```powershell
Get-Process | Out-File processes.txt -Encoding utf8 -Width 200
```

.NET 精确写入：

```powershell
[IO.File]::WriteAllText('file.txt', "hello`n", [Text.UTF8Encoding]::new($false))
```

不同 PowerShell 版本中 `utf8` 是否带 BOM 曾有差异；跨工具严格要求时使用 .NET 显式控制。

## 11. 搜索文本：`Select-String`

```powershell
Select-String -Path '*.log' -Pattern 'error'
Select-String -Path '*.log' -Pattern 'error' -CaseSensitive
Select-String -Path '*.log' -Pattern 'error' -SimpleMatch
Select-String -Path '*.log' -Pattern 'error' -Context 2,3
```

递归：

```powershell
Get-ChildItem -Recurse -File '*.log' |
  Select-String -Pattern 'timeout'
```

只取匹配：

```powershell
Select-String file.txt -Pattern '\d+' -AllMatches |
  ForEach-Object Matches |
  ForEach-Object Value
```

## 12. 字符串操作

```powershell
$text = '  Hello World  '
$text.Trim()
$text.ToLowerInvariant()
$text.Replace('World', 'PowerShell')
$text.Split(' ')
$text.Contains('Hello')
$text.StartsWith('  He')
```

PowerShell 运算符：

```powershell
'hello world' -replace 'world', 'PowerShell'
'a,b,c' -split ','
('a','b','c') -join ';'
'file.txt' -like '*.txt'
'abc123' -match '\d+'
$Matches[0]
```

`-replace` 和 `-split` 默认使用正则表达式。

## 13. CSV、JSON、XML

CSV：

```powershell
$data | Export-Csv data.csv -NoTypeInformation -Encoding utf8
$data = Import-Csv data.csv
```

JSON：

```powershell
$json = $data | ConvertTo-Json -Depth 10
$json | Set-Content data.json -Encoding utf8
$data = Get-Content data.json -Raw | ConvertFrom-Json
```

XML：

```powershell
[xml]$xml = Get-Content config.xml -Raw
$xml.DocumentElement
```

## 14. 哈希、压缩和归档

哈希：

```powershell
Get-FileHash file.zip -Algorithm SHA256
```

创建 ZIP：

```powershell
Compress-Archive -Path output\* -DestinationPath release.zip -CompressionLevel Optimal
```

覆盖已有 ZIP：

```powershell
Compress-Archive -Path output\* -DestinationPath release.zip -Force
```

解压：

```powershell
Expand-Archive release.zip -DestinationPath extracted -Force
```

`Compress-Archive` 对超大文件、隐藏文件和某些元数据有局限；大型发布包可考虑 `tar.exe` 或 7-Zip。

## 15. 临时文件

```powershell
$tempFile = New-TemporaryFile
$tempDir = Join-Path ([IO.Path]::GetTempPath()) ([guid]::NewGuid())
New-Item -ItemType Directory $tempDir | Out-Null
```

清理：

```powershell
Remove-Item $tempFile -Force
Remove-Item $tempDir -Recurse -Force
```
