# 01：基础语法、帮助与命令发现

## 1. Cmdlet、函数、别名和外部程序

PowerShell 命令可能是 cmdlet、函数、脚本、别名或外部程序。

```powershell
Get-Command Get-ChildItem
Get-Command python
Get-Command cd -All
```

`Get-Command` 返回命令对象。常用参数：

| 参数 | 作用 |
|---|---|
| `-Name` | 按名称查找，支持 `*` 通配符 |
| `-CommandType` | 限定 `Cmdlet`、`Function`、`Alias`、`Application` 等 |
| `-Module` | 只查指定模块 |
| `-All` | 返回所有同名命令，而非优先级最高的一个 |

判断实际会执行哪个程序：

```powershell
(Get-Command python).Source
```

Windows 的 `where.exe` 只查 PATH 中的外部程序：

```powershell
where.exe python
```

不要写 `where python` 来代替，因为 `where` 在 PowerShell 中可能被解释成 `Where-Object` 的别名。

## 2. 帮助系统

```powershell
Get-Help Get-ChildItem
Get-Help Get-ChildItem -Detailed
Get-Help Get-ChildItem -Full
Get-Help Get-ChildItem -Examples
Get-Help Get-ChildItem -Parameter Filter
Get-Help Get-ChildItem -Online
```

- `-Detailed`：含参数说明和示例。
- `-Full`：最完整本地帮助。
- `-Examples`：只看示例。
- `-Parameter`：只查一个参数。
- `-Online`：打开官方网页。

搜索帮助主题：

```powershell
Get-Help about_*
Get-Help about_Quoting_Rules
Get-Help about_Automatic_Variables
```

更新帮助：

```powershell
Update-Help
```

可能需要管理员权限和网络。

## 3. 命令结构

```powershell
Get-ChildItem -Path C:\Windows -Filter '*.dll' -File
```

- `Get-ChildItem`：命令。
- `-Path C:\Windows`：参数和参数值。
- `-Filter '*.dll'`：由文件系统 provider 提前筛选，通常比管道过滤快。
- `-File`：开关参数，出现即表示真。

参数名可以缩写到没有歧义，但脚本中建议写完整：

```powershell
Get-ChildItem -Recurse     # 推荐
Get-ChildItem -Rec         # 能运行，但可读性差
```

## 4. 引号

### 单引号

内容按字面值处理：

```powershell
$name = 'Alice'
'Hello $name'       # Hello $name
```

单引号内表示一个单引号：

```powershell
'It''s fine'
```

### 双引号

展开变量和表达式：

```powershell
$name = 'Alice'
"Hello $name"      # Hello Alice
"2 + 3 = $(2 + 3)" # 2 + 3 = 5
```

变量名边界不清时使用花括号：

```powershell
"${name}_backup"
```

### Here-string

多行字面文本：

```powershell
$text = @'
第一行
$name 不会展开
'@
```

多行插值文本：

```powershell
$text = @"
第一行
$name 会展开
"@
```

结束标记必须独占一行并顶格。

## 5. 转义字符

PowerShell 转义字符是反引号 `` ` ``：

```powershell
"第一行`n第二行"
"制表`t符"
"美元符号：`$"
"双引号：`""
```

常见转义：

| 写法 | 含义 |
|---|---|
| `` `n `` | 换行 |
| `` `r `` | 回车 |
| `` `t `` | 制表符 |
| `` `0 `` | NUL |
| `` `` ` `` | 反引号本身 |
| `` `$ `` | 字面 `$` |
| `` `" `` | 双引号 |

## 6. 换行与语句分隔

分号分隔语句：

```powershell
$a = 1; $b = 2; $a + $b
```

反引号续行：

```powershell
Get-ChildItem `
  -Path C:\Windows `
  -Filter '*.dll'
```

反引号后不能有空格。更稳妥的方法是利用括号、数组和管道自然续行：

```powershell
$items = @(
  'one'
  'two'
)

Get-Process |
  Where-Object CPU -gt 10 |
  Sort-Object CPU -Descending
```

## 7. 注释

单行：

```powershell
# 这是注释
Get-Date # 行尾注释
```

块注释：

```powershell
<#
多行注释
不会执行
#>
```

函数帮助可使用 comment-based help：

```powershell
function Get-Greeting {
<#!
.SYNOPSIS
返回问候语。
.PARAMETER Name
要问候的人。
.EXAMPLE
Get-Greeting -Name Alice
#>
  param([string]$Name)
  "Hello $Name"
}
```

实际开始标记应写成 `<#`，上例中去掉为避免文档解析歧义而显示的感叹号即可。

## 8. 调用运算符 `&`

变量中保存的命令路径不会自动执行：

```powershell
$exe = 'C:\Program Files\App\app.exe'
& $exe --version
```

`&` 只执行命令，不重新解析整段字符串：

```powershell
$args = @('--name', 'Alice Smith')
& $exe @args
```

这比拼接一个大字符串安全。

## 9. 停止解析符 `--%`

Windows PowerShell 可用 `--%` 将后续内容原样交给原生程序：

```powershell
some.exe --% --regex ^a\d+$
```

限制：变量通常不再按正常 PowerShell 规则展开；PowerShell 7 中建议优先使用参数数组。

## 10. 表达式与子表达式

```powershell
2 + 3
(2 + 3) * 4
$name = (Get-Item '.').Name
"当前目录：$(Get-Location)"
```

- `()`：分组或先求值。
- `$()`：在双引号字符串中执行复杂表达式。
- `@()`：强制结果成为数组。
- `@{}`：哈希表。

## 11. 重定向

```powershell
command.exe > output.txt
command.exe >> output.txt
command.exe 2> error.txt
command.exe *> all.txt
command.exe 2>&1
```

| 写法 | 含义 |
|---|---|
| `>` | 覆盖标准输出文件 |
| `>>` | 追加 |
| `2>` | 错误流 |
| `*>` | 所有 PowerShell 流 |
| `2>&1` | 将错误流合并到成功流 |

需要控制编码时优先使用：

```powershell
command.exe | Set-Content -Encoding utf8 output.txt
```

## 12. 查看历史

```powershell
Get-History
Invoke-History 12
Clear-History
```

`Get-History` 只表示当前会话历史；PSReadLine 可能另有持久历史文件：

```powershell
(Get-PSReadLineOption).HistorySavePath
```
