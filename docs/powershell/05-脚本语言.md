# 05：变量、集合、条件、循环、函数与脚本

## 1. 变量

```powershell
$name = 'Alice'
$count = 3
$enabled = $true
$nothing = $null
```

变量名不区分大小写。查看变量：

```powershell
Get-Variable
Get-Variable name
```

删除：

```powershell
Remove-Variable name
```

只读变量：

```powershell
New-Variable -Name ApiVersion -Value 'v1' -Option ReadOnly
```

显式类型：

```powershell
[int]$count = 10
[string]$name = 'Alice'
[datetime]$date = '2026-10-03'
```

严格模式：

```powershell
Set-StrictMode -Version Latest
```

它会更早发现未初始化变量和无效属性，建议脚本使用。

## 2. 自动变量

常用自动变量：

| 变量 | 含义 |
|---|---|
| `$_` / `$PSItem` | 当前管道对象 |
| `$args` | 未绑定参数 |
| `$input` | 管道输入枚举器 |
| `$PWD` | 当前目录对象 |
| `$HOME` | 用户主目录 |
| `$PID` | 当前 PowerShell 进程 ID |
| `$PSVersionTable` | 版本信息 |
| `$PSScriptRoot` | 当前脚本所在目录 |
| `$PSCommandPath` | 当前脚本完整路径 |
| `$LASTEXITCODE` | 最近原生程序退出码 |
| `$?` | 最近命令是否成功 |
| `$Error` | 当前会话错误集合 |
| `$Matches` | 最近一次 `-match` 捕获结果 |

## 3. 数组

```powershell
$numbers = @(1,2,3)
$names = 'Alice','Bob','Carol'
$empty = @()
```

访问：

```powershell
$names[0]
$names[-1]
$names[1..2]
$names.Count
```

追加：

```powershell
$names += 'Dave'
```

频繁追加大数组性能较差，可用泛型列表：

```powershell
$list = [Collections.Generic.List[string]]::new()
$list.Add('Alice')
$list.Add('Bob')
```

强制单个结果成为数组：

```powershell
$files = @(Get-ChildItem -File)
$files.Count
```

## 4. 哈希表和有序字典

```powershell
$config = @{
  Host = 'localhost'
  Port = 8080
}
$config['Host']
$config.Port
```

修改和新增：

```powershell
$config.Port = 9090
$config.Enabled = $true
```

有序：

```powershell
$config = [ordered]@{
  First = 1
  Second = 2
}
```

遍历：

```powershell
foreach ($entry in $config.GetEnumerator()) {
  "$($entry.Key)=$($entry.Value)"
}
```

## 5. 类型转换

```powershell
[int]'42'
[double]'3.14'
[datetime]'2026-10-03 18:24'
[version]'1.2.3'
[bool]1
```

安全解析：

```powershell
$value = 0
if ([int]::TryParse('42', [ref]$value)) {
  $value
}
```

查看类型：

```powershell
$value.GetType().FullName
$value -is [int]
$value -as [string]
```

## 6. 运算符

算术：

```powershell
1 + 2
5 - 3
4 * 2
10 / 4
10 % 3
2 -shl 3
```

逻辑：

```powershell
$true -and $false
$true -or $false
-not $true
```

比较：

```powershell
$a -eq $b
$a -ne $b
$a -gt $b
$a -ge $b
$a -lt $b
$a -le $b
```

范围：

```powershell
1..10
10..1
```

空值合并（PowerShell 7）：

```powershell
$value = $possiblyNull ?? 'default'
$possiblyNull ??= 'default'
```

三元运算（PowerShell 7）：

```powershell
$message = $ok ? '成功' : '失败'
```

## 7. `if` / `elseif` / `else`

```powershell
if ($score -ge 90) {
  '优秀'
} elseif ($score -ge 60) {
  '及格'
} else {
  '不及格'
}
```

PowerShell 条件真值规则中，非空字符串和多数非零值为真。需要明确时使用比较运算符。

## 8. `switch`

```powershell
switch ($status) {
  'Ready' { '准备完成'; break }
  'Error' { '发生错误'; break }
  default { '未知状态' }
}
```

通配符：

```powershell
switch -Wildcard ($fileName) {
  '*.txt' { '文本文件' }
  '*.json' { 'JSON 文件' }
  default { '其他' }
}
```

正则：

```powershell
switch -Regex ($text) {
  '^\d+$' { '全是数字' }
  '^[a-z]+$' { '全是字母' }
}
```

处理文件每行：

```powershell
switch -File file.txt {
  { $_ -match 'error' } { $_ }
}
```

## 9. 循环

### `foreach` 语句

```powershell
foreach ($name in $names) {
  "Hello $name"
}
```

适合已经在内存中的集合，通常比 `ForEach-Object` 快。

### `for`

```powershell
for ($i = 0; $i -lt 10; $i++) {
  $i
}
```

### `while`

```powershell
$i = 0
while ($i -lt 3) {
  $i++
}
```

### `do`

```powershell
do {
  $answer = Read-Host '输入 yes'
} until ($answer -eq 'yes')
```

控制：

```powershell
break
continue
```

命名标签可控制外层循环：

```powershell
:outer foreach ($a in 1..3) {
  foreach ($b in 1..3) {
    if ($b -eq 2) { break outer }
  }
}
```

## 10. 函数

简单函数：

```powershell
function Get-Greeting {
  param([string]$Name)
  "Hello $Name"
}
Get-Greeting -Name Alice
```

高级函数：

```powershell
function Copy-SafeFile {
  [CmdletBinding(SupportsShouldProcess)]
  param(
    [Parameter(Mandatory, ValueFromPipeline)]
    [ValidateScript({ Test-Path $_ -PathType Leaf })]
    [string]$Path,

    [Parameter(Mandatory)]
    [string]$Destination
  )

  process {
    if ($PSCmdlet.ShouldProcess($Path, "Copy to $Destination")) {
      Copy-Item -LiteralPath $Path -Destination $Destination
    }
  }
}
```

这样自动支持：

```powershell
Copy-SafeFile -Path a.txt -Destination backup -WhatIf
Copy-SafeFile -Path a.txt -Destination backup -Verbose
```

## 11. 参数验证

```powershell
param(
  [Parameter(Mandatory)]
  [ValidateNotNullOrEmpty()]
  [string]$Name,

  [ValidateRange(1,100)]
  [int]$Count = 1,

  [ValidateSet('Debug','Release')]
  [string]$Mode = 'Release',

  [switch]$Force
)
```

- `[switch]`：出现即为 `$true`。
- 默认值让参数可选。
- `Mandatory` 会提示用户输入。

## 12. Splatting

哈希表参数展开：

```powershell
$params = @{
  Path = 'C:\Windows'
  Filter = '*.dll'
  File = $true
}
Get-ChildItem @params
```

数组参数展开给外部程序：

```powershell
$args = @('--input','file with spaces.txt','--verbose')
& app.exe @args
```

## 13. 作用域

```powershell
$global:Name = 'global'
$script:Name = 'script'
$local:Name = 'local'
$private:Name = 'private'
```

函数内部默认创建局部变量。修改外层变量需要明确作用域，但更好的设计是返回值而不是依赖全局状态。

## 14. 脚本文件和执行策略

运行脚本：

```powershell
.\script.ps1
```

临时绕过当前进程执行策略：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\script.ps1
```

查看：

```powershell
Get-ExecutionPolicy -List
```

为当前用户设置：

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

执行策略不是安全边界，只是防止意外运行脚本。

## 15. Dot sourcing

```powershell
. .\functions.ps1
```

第一个点是 dot-source 运算符。脚本中的函数和变量会加载到当前作用域。普通执行则在子作用域运行。

## 17. 类与枚举

```powershell
enum Status {
  Ready
  Running
  Failed
}

class JobInfo {
  [string]$Name
  [Status]$Status
  JobInfo([string]$name) {
    $this.Name = $name
    $this.Status = [Status]::Ready
  }
}

$job = [JobInfo]::new('demo')
```

复杂可复用模块可使用类，但日常数据传递通常 `[pscustomobject]` 更轻便。
