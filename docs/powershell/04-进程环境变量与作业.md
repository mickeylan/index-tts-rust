# 04：进程、外部程序、环境变量与作业

## 1. 查看进程：`Get-Process`

```powershell
Get-Process
Get-Process powershell
Get-Process -Id $PID
```

常用属性：

```powershell
Get-Process | Select-Object ProcessName, Id, CPU, WorkingSet64, Path
```

某些属性需要管理员权限，且访问已退出进程可能失败。

按内存排序：

```powershell
Get-Process |
  Sort-Object WorkingSet64 -Descending |
  Select-Object -First 10 ProcessName,Id,@{
    Name='MemoryMB'; Expression={[math]::Round($_.WorkingSet64/1MB,1)}
  }
```

## 2. 启动进程：直接调用与 `Start-Process`

直接调用并等待：

```powershell
python --version
& 'C:\Program Files\App\app.exe' --version
```

PowerShell 会等待控制台程序，并可读取 `$LASTEXITCODE`。

`Start-Process`：

```powershell
Start-Process notepad.exe
Start-Process file.wav
Start-Process https://example.com
```

等待和获取进程对象：

```powershell
$p = Start-Process app.exe -ArgumentList '--mode','test' -PassThru -Wait
$p.ExitCode
```

重定向：

```powershell
$p = Start-Process app.exe `
  -ArgumentList '--version' `
  -RedirectStandardOutput stdout.txt `
  -RedirectStandardError stderr.txt `
  -PassThru -Wait
```

管理员启动：

```powershell
Start-Process powershell.exe -Verb RunAs
```

注意：`-ArgumentList` 最终会拼成命令行；复杂引号参数需要特别测试。普通控制台调用优先使用 `&` 和参数数组。

## 3. 停止和等待进程

```powershell
Stop-Process -Id 1234
Stop-Process -Name app
Stop-Process -Id 1234 -Force
Wait-Process -Id 1234
```

预演：

```powershell
Stop-Process -Name app -WhatIf
```

不要按模糊名称批量结束系统进程。

## 4. 外部程序参数数组

```powershell
$exe = 'C:\Program Files\App\app.exe'
$arguments = @('--input', 'C:\path with spaces\file.txt', '--verbose')
& $exe @arguments
$code = $LASTEXITCODE
```

数组 splatting 能保持每个参数的边界，比构造一整条字符串可靠。

## 5. `$LASTEXITCODE` 与 `$?`

```powershell
python --version
$LASTEXITCODE
$?
```

- `$LASTEXITCODE`：最近一个原生程序退出码。
- `$?`：最近一个命令整体是否成功的布尔值。

严谨检查：

```powershell
& $exe @arguments
$code = $LASTEXITCODE
if ($code -ne 0) {
  throw "程序失败，退出码：$code"
}
```

要立即保存退出码；运行另一个原生程序会覆盖它。

## 6. 环境变量

列出：

```powershell
Get-ChildItem Env:
```

读取：

```powershell
$env:Path
[Environment]::GetEnvironmentVariable('Path', 'Process')
```

设置当前进程：

```powershell
$env:MY_SETTING = 'value'
```

删除：

```powershell
Remove-Item Env:MY_SETTING
```

持久写入用户环境：

```powershell
[Environment]::SetEnvironmentVariable('MY_SETTING', 'value', 'User')
```

持久写入系统环境需要管理员权限：

```powershell
[Environment]::SetEnvironmentVariable('MY_SETTING', 'value', 'Machine')
```

持久设置不会自动刷新已打开的进程。

## 7. 安全修改 PATH

当前进程前置目录：

```powershell
$env:Path = 'C:\Tools;' + $env:Path
```

先保存再恢复：

```powershell
$oldPath = $env:Path
try {
  $env:Path = 'C:\Tools;' + $env:Path
  # 执行命令
} finally {
  $env:Path = $oldPath
}
```

避免重复加入：

```powershell
$dir = 'C:\Tools'
$parts = $env:Path -split ';' | Where-Object { $_ }
if ($dir -notin $parts) {
  $env:Path = $dir + ';' + $env:Path
}
```

## 8. 服务管理

```powershell
Get-Service
Get-Service -Name Spooler
Start-Service Spooler
Stop-Service Spooler
Restart-Service Spooler
Set-Service Spooler -StartupType Automatic
```

更改服务通常需要管理员权限。查看依赖：

```powershell
Get-Service Spooler -DependentServices
Get-Service Spooler -RequiredServices
```

## 9. PowerShell 后台作业

启动：

```powershell
$job = Start-Job { Get-ChildItem C:\Windows -Recurse -ErrorAction SilentlyContinue }
```

查看：

```powershell
Get-Job
$job | Wait-Job
$job | Receive-Job
```

清理：

```powershell
$job | Stop-Job
$job | Remove-Job
```

`Start-Job` 在独立进程中运行，对象会序列化，不能自动继承当前变量。传参数：

```powershell
$path = 'C:\Windows'
Start-Job -ArgumentList $path -ScriptBlock {
  param($TargetPath)
  Get-ChildItem $TargetPath
}
```

## 10. 线程作业

PowerShell 7 可使用：

```powershell
Start-ThreadJob { Get-Date }
```

可能需要模块：

```powershell
Install-Module ThreadJob -Scope CurrentUser
Import-Module ThreadJob
```

线程作业启动更快，但共享同一进程，原生库线程安全问题需要额外注意。

## 11. 计划任务

查看：

```powershell
Get-ScheduledTask
```

创建动作和触发器：

```powershell
$action = New-ScheduledTaskAction -Execute 'powershell.exe' -Argument '-File C:\Scripts\job.ps1'
$trigger = New-ScheduledTaskTrigger -Daily -At 3am
Register-ScheduledTask -TaskName 'DailyJob' -Action $action -Trigger $trigger
```

删除：

```powershell
Unregister-ScheduledTask -TaskName 'DailyJob' -Confirm:$false
```

## 12. 等待、睡眠和超时

```powershell
Start-Sleep -Seconds 2
Start-Sleep -Milliseconds 250
```

等待进程最多 30 秒的简单写法：

```powershell
$p = Start-Process app.exe -PassThru
if (-not $p.WaitForExit(30000)) {
  $p.Kill()
  throw '程序超时'
}
```

## 13. 查看命令耗时

简单测量：

```powershell
Measure-Command { Get-ChildItem C:\Windows -Recurse }
```

需要同时保留输出和退出码时：

```powershell
$timer = [Diagnostics.Stopwatch]::StartNew()
& $exe @arguments
$code = $LASTEXITCODE
$timer.Stop()
[pscustomobject]@{ ExitCode=$code; Seconds=$timer.Elapsed.TotalSeconds }
```

## 14. 打开程序、文件和 URL

```powershell
Invoke-Item .
Invoke-Item report.html
Start-Process result.wav
Start-Process 'https://learn.microsoft.com/powershell/'
```

`Invoke-Item` 使用文件关联打开；别名 `ii`。
