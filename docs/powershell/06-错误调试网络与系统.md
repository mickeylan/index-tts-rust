# 06：错误处理、调试、网络与系统管理

## 1. PowerShell 错误类型

- 终止错误：立即终止当前语句，可被 `try/catch` 捕获。
- 非终止错误：记录错误后继续，默认不进入 `catch`。
- 原生程序失败：通常只设置 `$LASTEXITCODE`，不会自动抛出 PowerShell 异常。

## 2. `$ErrorActionPreference`

```powershell
$ErrorActionPreference = 'Stop'
```

常见值：

| 值 | 行为 |
|---|---|
| `Continue` | 显示错误并继续，默认 |
| `Stop` | 转为终止错误 |
| `SilentlyContinue` | 不显示，但保存到 `$Error` |
| `Ignore` | 不显示且不保存 |
| `Inquire` | 询问用户 |

单命令覆盖：

```powershell
Get-Item missing.txt -ErrorAction Stop
```

简写公共参数：

```powershell
Get-Item missing.txt -EA Stop
```

脚本建议保存并恢复全局偏好，或优先逐条指定。

## 3. `try` / `catch` / `finally`

```powershell
try {
  Get-Item missing.txt -ErrorAction Stop
} catch {
  Write-Error "读取失败：$($_.Exception.Message)"
} finally {
  '无论成功失败都会执行'
}
```

错误对象：

```powershell
catch {
  $_.Exception.GetType().FullName
  $_.Exception.Message
  $_.InvocationInfo.PositionMessage
  $_.ScriptStackTrace
}
```

按类型捕获：

```powershell
try {
  [IO.File]::ReadAllText('missing.txt')
} catch [IO.FileNotFoundException] {
  '文件不存在'
} catch {
  throw
}
```

## 4. `throw` 与 `trap`

```powershell
if (-not (Test-Path $path)) {
  throw "文件不存在：$path"
}
```

重新抛出当前错误：

```powershell
catch {
  Write-Warning $_
  throw
}
```

`trap` 是较旧的作用域错误处理机制：

```powershell
trap { Write-Warning $_; continue }
```

现代脚本优先使用 `try/catch/finally`。

## 5. 原生程序错误

```powershell
& app.exe --run
$code = $LASTEXITCODE
if ($code -ne 0) {
  throw "app.exe 失败，退出码 $code"
}
```

捕获输出和错误：

```powershell
$output = & app.exe --run 2>&1
$code = $LASTEXITCODE
if ($code -ne 0) {
  throw "失败：`n$($output -join "`n")"
}
```

注意：合并后输出对象可能包含 `ErrorRecord`，不一定全是普通字符串。

## 6. 消息流

```powershell
Write-Output '成功输出'
Write-Error '错误'
Write-Warning '警告'
Write-Verbose '详细信息'
Write-Debug '调试信息'
Write-Information '信息流'
Write-Host '直接显示'
```

启用 verbose/debug：

```powershell
$VerbosePreference = 'Continue'
$DebugPreference = 'Continue'
```

高级函数可通过 `-Verbose`、`-Debug` 控制。

`Write-Output` 进入成功管道；`Write-Host` 主要用于界面提示，不适合返回业务数据。

## 7. 调试脚本

设置断点：

```powershell
Set-PSBreakpoint -Script .\script.ps1 -Line 20
Set-PSBreakpoint -Command Remove-Item
Set-PSBreakpoint -Variable state -Mode Write
```

查看和删除：

```powershell
Get-PSBreakpoint
Remove-PSBreakpoint -Id 1
```

交互调试常用命令：

```text
s  StepInto
v  StepOver
o  StepOut
c  Continue
q  Stop
k  Call stack
l  List source
```

跟踪执行：

```powershell
Set-PSDebug -Trace 1
Set-PSDebug -Off
```

## 8. Transcript

记录会话：

```powershell
Start-Transcript -Path session.log -Append
# 执行命令
Stop-Transcript
```

Transcript 不是完整审计机制，某些本机程序输出或敏感输入可能处理不同。不要把凭据写进日志。

## 9. 事件日志

查看日志：

```powershell
Get-WinEvent -ListLog *
Get-WinEvent -LogName System -MaxEvents 20
```

筛选：

```powershell
Get-WinEvent -FilterHashtable @{
  LogName = 'System'
  Level = 2
  StartTime = (Get-Date).AddHours(-24)
}
```

`Level = 2` 通常表示 Error。管理员权限可能影响可读日志。

旧命令 `Get-EventLog` 仅适用于经典事件日志；新脚本优先 `Get-WinEvent`。

## 10. 日期和时间

```powershell
Get-Date
Get-Date -Format 'yyyy-MM-dd HH:mm:ss'
(Get-Date).AddDays(-7)
[datetime]::UtcNow
```

解析：

```powershell
[datetime]::Parse('2026-10-03 18:24')
[datetime]::ParseExact('20261003','yyyyMMdd',$null)
```

时间差：

```powershell
$start = Get-Date
Start-Sleep 1
$elapsed = (Get-Date) - $start
$elapsed.TotalSeconds
```

## 11. HTTP：`Invoke-WebRequest`

```powershell
$response = Invoke-WebRequest 'https://example.com'
$response.StatusCode
$response.Content
$response.Headers
```

下载：

```powershell
Invoke-WebRequest $url -OutFile installer.exe
```

Headers：

```powershell
Invoke-WebRequest $url -Headers @{ Authorization = "Bearer $token" }
```

不要把 token 直接打印或硬编码到脚本仓库。

## 12. REST：`Invoke-RestMethod`

GET JSON：

```powershell
$data = Invoke-RestMethod 'https://api.example.com/items'
$data.items
```

POST JSON：

```powershell
$body = @{ name='demo'; enabled=$true } | ConvertTo-Json
$result = Invoke-RestMethod `
  -Uri 'https://api.example.com/items' `
  -Method Post `
  -ContentType 'application/json' `
  -Body $body
```

超时：

```powershell
Invoke-RestMethod $url -TimeoutSec 30
```

## 13. 网络诊断

```powershell
Test-Connection example.com -Count 4
Test-NetConnection example.com -Port 443
Resolve-DnsName example.com
```

## 15. 注册表

PowerShell 将注册表作为 provider：

```powershell
Get-ChildItem HKCU:\Software
Get-ItemProperty 'HKCU:\Software\Example'
New-Item 'HKCU:\Software\Example' -Force
Set-ItemProperty 'HKCU:\Software\Example' -Name Enabled -Value 1
Remove-Item 'HKCU:\Software\Example' -Recurse
```

修改前先导出或记录原值。HKLM 通常需要管理员权限。

## 16. 权限和管理员判断

```powershell
$identity = [Security.Principal.WindowsIdentity]::GetCurrent()
$principal = [Security.Principal.WindowsPrincipal]::new($identity)
$isAdmin = $principal.IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
$isAdmin
```

以管理员重新启动：

```powershell
Start-Process powershell.exe -Verb RunAs -ArgumentList '-NoProfile','-File',"`"$PSCommandPath`""
```

## 17. 凭据和秘密

交互读取安全字符串：

```powershell
$secure = Read-Host '密码' -AsSecureString
$credential = Get-Credential
```

环境变量仍可被当前用户进程读取，不是秘密保险箱。生产秘密应使用 Windows Credential Manager、SecretManagement、CI secret 或专门密钥系统。

安装 SecretManagement：

```powershell
Install-Module Microsoft.PowerShell.SecretManagement -Scope CurrentUser
Get-SecretVault
```

## 18. 远程管理

启用（管理员）：

```powershell
Enable-PSRemoting -Force
```

单次执行：

```powershell
Invoke-Command -ComputerName Server01 -ScriptBlock { Get-Date }
```

会话：

```powershell
$session = New-PSSession -ComputerName Server01
Invoke-Command -Session $session -ScriptBlock { Get-Process }
Remove-PSSession $session
```

远程管理涉及认证、WinRM、防火墙和可信主机配置，不要为图方便禁用安全校验。

## 19. 常用安全开头

```powershell
Set-StrictMode -Version Latest
$ErrorActionPreference = 'Stop'

try {
  # PowerShell cmdlet
  Get-Item $path -ErrorAction Stop

  # 原生程序
  & $exe @arguments
  if ($LASTEXITCODE -ne 0) {
    throw "$exe failed with exit code $LASTEXITCODE"
  }
} catch {
  Write-Error $_
  exit 1
}
```
