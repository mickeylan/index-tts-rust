# 02：对象、管道、筛选、排序与格式化

PowerShell 管道传递的是 .NET 对象，不只是文本。这是它与传统 shell 最重要的差别。

## 1. 查看对象类型和成员

```powershell
$item = Get-Item C:\Windows
$item.GetType().FullName
$item | Get-Member
```

`Get-Member` 显示：

- `Property`：属性；
- `Method`：方法；
- `ScriptProperty`、`AliasProperty`：PowerShell 扩展成员。

只看属性：

```powershell
$item | Get-Member -MemberType Property
```

读取属性：

```powershell
$item.FullName
$item.LastWriteTime
```

调用方法：

```powershell
'hello'.ToUpper()
```

## 2. 管道 `|`

```powershell
Get-Process | Sort-Object CPU -Descending
```

左侧输出对象，右侧逐个或成批接收。查看某命令接受哪些管道输入：

```powershell
Get-Help Stop-Process -Full
```

寻找 `Accept pipeline input`。

## 3. `Where-Object`：筛选

完整形式：

```powershell
Get-Process | Where-Object { $_.CPU -gt 10 }
```

- `$_`：当前管道对象。
- `{}`：脚本块。
- `-gt`：大于。

简写形式：

```powershell
Get-Process | Where-Object CPU -gt 10
```

多条件：

```powershell
Get-Process | Where-Object {
  $_.CPU -gt 10 -and $_.WorkingSet64 -gt 500MB
}
```

常用比较运算符：

| 运算符 | 含义 |
|---|---|
| `-eq` / `-ne` | 等于 / 不等于 |
| `-gt` / `-ge` | 大于 / 大于等于 |
| `-lt` / `-le` | 小于 / 小于等于 |
| `-like` / `-notlike` | 通配符匹配 |
| `-match` / `-notmatch` | 正则匹配 |
| `-contains` | 集合包含值 |
| `-in` | 值位于集合中 |
| `-is` | 类型判断 |

默认字符串比较不区分大小写；前缀 `c` 表示区分大小写：

```powershell
'A' -eq 'a'   # True
'A' -ceq 'a'  # False
```

## 4. `ForEach-Object`：管道迭代

```powershell
1..3 | ForEach-Object { $_ * 2 }
```

属性简写：

```powershell
Get-Process | ForEach-Object ProcessName
```

调用方法：

```powershell
'one','two' | ForEach-Object ToUpper
```

带 begin/process/end：

```powershell
1..5 | ForEach-Object -Begin {
  $sum = 0
} -Process {
  $sum += $_
} -End {
  $sum
}
```

PowerShell 7 并行执行：

```powershell
1..10 | ForEach-Object -Parallel { "$_ on $PID" } -ThrottleLimit 4
```

并行有序列化和启动成本，不适合极小任务。

## 5. `Select-Object`：选择和计算属性

选择属性：

```powershell
Get-Process | Select-Object ProcessName, Id, CPU
```

前几个或后几个：

```powershell
Get-Process | Select-Object -First 5
Get-Process | Select-Object -Last 5
```

去重：

```powershell
Get-Process | Select-Object ProcessName -Unique
```

计算属性：

```powershell
Get-Process | Select-Object ProcessName, @{
  Name = 'MemoryMB'
  Expression = { [math]::Round($_.WorkingSet64 / 1MB, 2) }
}
```

`Name` 是新属性名，`Expression` 是计算脚本块。

展开单个属性：

```powershell
Get-Process | Select-Object -ExpandProperty ProcessName
```

与普通选择不同，`-ExpandProperty` 输出属性值本身。

## 6. `Sort-Object`：排序

```powershell
Get-Process | Sort-Object CPU
Get-Process | Sort-Object CPU -Descending
```

多字段：

```powershell
Get-ChildItem | Sort-Object Extension, Name
```

每列独立方向：

```powershell
Get-Process | Sort-Object `
  @{ Expression = 'CPU'; Descending = $true },
  @{ Expression = 'ProcessName'; Descending = $false }
```

## 7. `Group-Object`：分组

```powershell
Get-Process | Group-Object ProcessName
```

按扩展名统计文件：

```powershell
Get-ChildItem -File | Group-Object Extension | Sort-Object Count -Descending
```

结果具有 `Name`、`Count`、`Group` 属性。

输出哈希表：

```powershell
$groups = Get-Process | Group-Object ProcessName -AsHashTable -AsString
$groups['chrome']
```

## 8. `Measure-Object`：统计

```powershell
1..10 | Measure-Object -Sum -Average -Minimum -Maximum
```

文件总大小：

```powershell
Get-ChildItem -File -Recurse | Measure-Object Length -Sum
```

字符、单词和行：

```powershell
Get-Content file.txt | Measure-Object -Line -Word -Character
```

## 9. `Compare-Object`：比较集合

```powershell
$a = 'one','two','three'
$b = 'two','three','four'
Compare-Object $a $b
```

`SideIndicator`：

- `<=`：只在参考集合 `$a`；
- `=>`：只在差异集合 `$b`。

按属性比较：

```powershell
Compare-Object $old $new -Property Name, Length
```

## 10. `Tee-Object`：一边保存一边继续

```powershell
Get-Process |
  Tee-Object -FilePath processes.txt |
  Where-Object CPU -gt 10
```

保存变量：

```powershell
Get-Process | Tee-Object -Variable allProcesses | Select-Object -First 5
```

## 11. 格式化命令

```powershell
Get-Process | Format-Table ProcessName, Id, CPU -AutoSize
Get-Process | Format-List *
Get-ChildItem | Format-Wide Name -Column 4
```

重要：`Format-*` 应放在管道末端。它输出格式指令，不再是原始业务对象：

```powershell
# 错误思路
Get-Process | Format-Table | Export-Csv processes.csv

# 正确
Get-Process | Select-Object ProcessName,Id,CPU | Export-Csv processes.csv
```

## 12. 导出结构化数据

CSV：

```powershell
Get-Process |
  Select-Object ProcessName,Id,CPU |
  Export-Csv processes.csv -NoTypeInformation -Encoding utf8
```

导入：

```powershell
$data = Import-Csv processes.csv
```

JSON：

```powershell
Get-Process | Select-Object -First 2 | ConvertTo-Json -Depth 4
```

写文件：

```powershell
Get-Process | Select-Object -First 2 |
  ConvertTo-Json -Depth 4 |
  Set-Content processes.json -Encoding utf8
```

读取：

```powershell
$data = Get-Content processes.json -Raw | ConvertFrom-Json
```

Clixml 保留更多 PowerShell 类型信息：

```powershell
Get-Process | Export-Clixml processes.xml
$data = Import-Clixml processes.xml
```

## 13. 创建自定义对象

```powershell
$result = [pscustomobject]@{
  Name = 'example'
  Success = $true
  DurationSeconds = 1.25
}
$result
```

适合生成表格、CSV 和 JSON。

## 14. `Out-*` 命令

```powershell
Get-Process | Out-Host
Get-Process | Out-File processes.txt -Encoding utf8
Get-Process | Out-GridView
'隐藏这段输出' | Out-Null
```

- `Out-Host`：明确发送到主机。
- `Out-File`：按显示格式写文本，不适合结构化数据。
- `Out-GridView`：Windows 图形表格；部分环境未安装。
- `Out-Null`：丢弃输出。
